## 四、当前系统演示流程

建议主线约5至7分钟，使用正式账号、正式课程及正式批次，不使用模拟组件页录制系统功能。

1. 学生登录 → 首页确认身份与兴趣 → 点击「查看个性化推荐」。首页实际是个人账户及入口，不能称为首页已有推荐卡片。
2. 展示画像兴趣权重、浏览/开始/完成/收藏次数、课程完成率和快照时间，说明离线统计不会在本次点击后即时变化。
3. 展示内容推荐综合得分、推荐原因；可切换热门算法，解释其热度量纲不同。
4. 学习资源列表搜索「PySpark」 → 详情 → 继续学习 → 展示目标、知识讲解、代码和练习 → 阅读后手动完成一个未完成章节，展示章节进度。录制时正常学习会增加正式行为，不要重复点击制造数据；不重跑Spark。
5. 返回推荐页，说明已完成课程过滤和离线画像更新边界。不能把完成一个章节说成整门课程已完成，也不能声称本次新行为已进入当前冻结批次。
6. 管理员登录 → 管理首页 → 课程管理 → 展示5门正式课程及章节管理入口，不执行修改、发布、下架。
7. 数据看板 → 行为趋势、资源分类、课程完成情况、推荐统计 → Spark批次页展示四阶段同源completed，结束。

页面检查结论：登录页表单清晰，账户首页入口可用；课程详情和正文学习可演示，画像与推荐数据可读；管理首页/课程管理/统计和批次页可演示。依据本轮静态审查、真实管理员看板和上一阶段正式双账号浏览器验收，不能扩大为本轮再次全流程实测。
