# 管理员后台模块设计

日期：2026-10-05。本阶段仅基础管理员管理；不开发AI问答、新算法、复杂权限、用户修改/禁用或批次执行功能。

## 目标与架构

新增管理员入口 `/admin`，Vue3/Element Plus提供用户只读列表、资源维护、Spark最近发布批次只读信息。复用现有JWT、require_admin和资源接口；不建表、不迁移、不修改推荐算法。前端路由检查角色只是展示保护，后端是最终权限边界。

未登录路由跳转登录；学习者访问/admin展示明确403页面（客户端页面不能设置HTTP响应状态，受保护接口真实返回403）。保留已有看板路由行为，不将学习者跳转机制全局改写。导航只对管理员显示入口。

## API与数据模型

- `GET /api/admin/users?page=1&page_size=20`：管理员只读，页长最大100；按id倒序返回items/total/page/page_size。仅返回id、username、role、status、created_at，不返回密码、兴趣或其他用户个人信息。拒绝额外目标用户参数。不允许用户创建/修改/删除。
- `GET /api/admin/batches`：读取固定位置的四个已发布指针：数据管道、用户画像、推荐计算、看板统计。返回阶段、批次编号、状态、生成/截止时间、数据量及口径、逻辑来源。此版展示各阶段最近发布批次，不承诺完整历史或运行中任务监控。文件缺失友好提示，损坏显示不可用，不把未知数据量写成0，不输出物理路径。后端只读文件，不运行Spark。
- 资源列表 `GET /api/resources` 使用status=all并支持标题搜索、分页及状态筛选；详情复用 `GET /api/resources/{id}`，不产生浏览事件。
- 新增/编辑分别复用 `POST /api/resources`、`PUT /api/resources/{id}`；新建为draft，编辑采用完整ResourceWrite字段替换。
- 发布/下架复用 `PATCH /api/resources/{id}/status`；draft→published、published→offline、offline→published沿用已有校验。草稿不能直接下架。已发布资源必须有标签及正文或外链。

## 表单与交互

字段严格沿用ResourceWrite：标题、简介、分类、资源类型、受控标签、难度、正文、公开HTTP外链、来源名称、许可说明。可空文本以null提交；限制长度与标签字典一致。状态/作者/版本由后端管理，不通过编辑表单覆盖。纯文本展示，不渲染用户输入HTML。

新增/编辑对话框显式保存；保存中禁用关闭与重复提交。状态操作明确标注对象并二次确认，失败保留现有数据并提示；不提供删除按钮。列表加载失败、空列表、分页以及成功提示独立处理。管理资源属于在线状态；批次统计属于冻结结果，资源修改不自动触发Spark重算。

## 实现与验证方案

后端增加admin schema/service/router，前端增加admin类型/API/页面及403页；不引入新依赖。只读用户表直接查询已有users，批次读固定文件白名单与结构校验。

测试包含401/403/管理员200、分页、字段最小化、真实发布文件读取、空或坏文件，以及已有资源接口的新增/编辑/发布/下架权限与状态转换。临时测试账号、资源限定随机前缀并清理，既有记录不修改。前端测试API参数、表单校验和路由权限；浏览器隔离模拟身份入口验证表格、对话框与交互，不把模拟组件测试当真实登录端到端验收。生产类型检查和构建必须通过。

完成本阶段设计、实现、测试、outputs/admin-module-acceptance-report.md后停止，等待用户确认。

## 实施决策与限制

已实现两条只读管理接口，未改变数据库。旧管道指针及质量报告缺生成时间，generated_at返回null；画像指针未记as_of_utc也返回null，页面显示未记录。发布记录中的completed表示已有元数据声明状态；本管理查询不重新执行Parquet校验或Spark任务。数据量明确区分清洗事件条数、画像行数、推荐行数、趋势自然日行数，不能相加解释为用户量。

客户端/admin的学习者保护跳转/403视图；HTTP SPA文档仍可能由Vite返回200，真实403由管理接口保证。资源页不提供删除、用户禁用、角色修改、批次触发或完整历史浏览。后端权限是最终边界。
