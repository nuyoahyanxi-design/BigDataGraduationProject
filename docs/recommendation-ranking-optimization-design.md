# 推荐排序优化设计

2026-10-05。不改数据库结构或API。原画像与事件保持；Spark推荐新增混合评分，仍用现有content_v1/popular_v1兼容接口标识，算法manifest版本升级以区分历史。

标签匹配T为显式兴趣（若快照提供）与资源标签的余弦相似度；无显式兴趣用画像权重。个人行为B为去重浏览（用户/资源/日）、开始、完成和当前收藏的1/2/3/2权重和，除以该用户最大资源行为权重。热度H为原全体热度除以候选池最大热度。均落在[0,1]，score=0.6T+0.25B+0.15H。无有效历史行为用户按热门排序，content分数使用归一化热度。完成/下架过滤与确定性排名不变。

SQL/MySQL/数据库归为database主题，Spark/PySpark/RDD归为spark主题，ml映射machine-learning，大数据映射big-data，仅在计算中去重/合并，不改业务标签。原6条数据库验收资源事实上全标python/spark，且明确source_name=本项目测试、license_note=仅供开发验收。推荐排除同时具有这两个标记的验收夹具，保留它们的数据与行为；不按标题猜测或屏蔽普通教学演示资源。

解释仅依据真实标签交集、直接行为或热门排序。不声称无热度资源实际受欢迎，零热度用“热门资源推荐：暂无历史热度，作为候选资源补充”，不暴露编号排序。

扩充受控标签以接纳指定5类资源。离线维护种子通过现有正式FastAPI路由及管理员JWT校验创建/发布，临时签名凭据只在进程，不改账号密码。已有同名同标签资源幂等跳过，冲突拒绝，不覆盖历史内容。新增资源后重新抽取/画像/推荐/看板发布新批次，保留旧批次不覆盖。历史实验数值不移植到新评分。

完成事件为资源带来热度，但已完成资源仍不再推荐给该用户；其主题兴趣可由现有画像保留。收藏取最新状态，取消收藏撤销该资源当前收藏贡献，重复无效事件不计入评分。

发布期间不运行修改业务数据的测试。代码摘要在模块导入时冻结，发布前后校验磁盘代码一致性；不删除此前失败或冲突批次，最终发布新的不可变批次。旧实验只有验收资源时新候选池为空，Coverage为不可计算；不能把旧覆盖率1当作新算法结果。
