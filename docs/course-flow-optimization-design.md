# 课程展示与学习流程优化设计

本阶段仅调整查询展示与章节导航，不改数据库结构、已有数据、推荐评分、Spark或AI。

## 展示隔离

定义唯一受控隐藏ID集合{406}。学习者资源列表（含搜索、分页总数）、详情与课程查询排除；管理员查询保留。推荐展示查询对所有用户过滤该资源，推荐结果存储及算法不动。看板资源数量与分类采用MySQL当前资源查询排除406，明确实时来源；用户、行为、学习等Spark指标仍保持批次口径，不伪装成同一快照。

## 学习状态

已有resources表没有completed字段，历史状态实际在learning_progress。存在章节时，按chapter_progress.completed_at非空数量/总章节数量动态计算：0章完成为not_started，部分完成为in_progress，全章完成为completed。无章节沿用原状态。GET课程、学习状态查询、章节事件新回执采用同一规则，历史事件幂等回执仍保留原结果，避免改变历史语义。推荐展示完成过滤同样使用该状态，仅改展示资格不改算法。

详情页章节课程按钮为开始课程/继续学习/重新学习，展示完成百分比。重新学习不重置章节完成记录。课程入口按position定位首个未完成章节（现有数据不提供最后访问时间；不声称可以恢复最近观看位置），全部完成定位最后章节。视频、Markdown、章节完成与事件事务保留。

## 验证

新增隔离账号和资源测试，结束仅清理本次临时夹具。检查新用户、部分及全部完成、历史状态冲突、隐藏列表/搜索/推荐/统计、管理员保留、导航和按钮。全量后端与前端测试，类型检查及生产构建，结果记录outputs。
