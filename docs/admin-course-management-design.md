# 管理员课程与章节维护设计

日期：2026-10-05。本阶段新增后台维护能力，不改数据库结构、现有课程数据、学习行为事务、推荐算法、用户画像、Spark或AI。

## 架构和接口

新增仅管理员路由/admin/courses，管理员后台及导航提供入口。课程即resource_type=course的既有resources行，列表/创建/修改/发布/隐藏复用现有资源接口；隐藏对应offline，不删除课程。章节读取复用GET /api/resources/{id}/course，新增复用POST /api/resources/{id}/chapters，新增PUT和DELETE /api/resources/{id}/chapters/{chapter_id}，仅require_admin可用。

使用既有字段title、position、video_url、content、learning_objectives、knowledge_tags、example_code、exercises。视频地址遵守现有本地静态资源白名单，支持/videos/*.mp4、webm及/demo/video.mp4，不引入上传或外部视频平台。Markdown沿用安全展示，后台不执行代码。用户身份、所属资源和章节归属在后端核验。

## 数据保护和事务

每次章节修改锁定管理员与资源，并验证章节归属。未发生章节学习时可维护目录，排序冲突返回409。课程发生任何chapter_progress或chapter_events后，冻结新增、删除及排序；文本、目标、知识点、示例、练习与视频可修改，不重置进度或历史事件。内容更新不代表用户重新完成，管理员须谨慎处理教学含义重大变化。

只有无学习记录的章节可物理删除，删除前页面二次确认；不删除学习进度、事件或课程资源。以资源行排他锁和既有学习行为资源锁协调并发，在同一事务内修改章节和递增资源版本/更新时间。异常整体回滚，删除已产生记录的章节拒绝。字段及路径校验继续使用ChapterWrite，不新增数据库字段或迁移。

## 页面和实现

课程列表包含搜索、状态筛选、分页、创建、编辑、发布/隐藏与章节管理。课程编辑强制course类型，提供标题、简介、分类、受控标签、难度和介绍等既有字段。选定课程后按position显示章节列表及新增/编辑表单；教学目标和练习按行输入，知识点以逗号分隔。保存失败保留输入；提交中禁止重复写入；服务端409展示准确限制。

## 验证计划

隔离测试账号与资源验证CRUD、权限401/403、归属404、排序及输入校验、历史学习后编辑保留进度/拒绝结构变更、事务回滚、并发与安全边界。测试后仅清理测试夹具。前端覆盖API参数、表单序列化、角色路由保护、实际组件操作及异常反馈。全量后端/前端测试、类型检查、生产构建；已有25章及数据库结构只读快照对比。阶段验收报告完成后停止。
