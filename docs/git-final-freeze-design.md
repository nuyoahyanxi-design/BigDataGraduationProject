# Git最终冻结整理设计

日期：2026-10-10。用户授权整理最终答辩提交候选，不授权自动提交。

## 目标与范围

逐项审查当前15个已跟踪修改和31个未跟踪文件。保留视频静态服务、自动发现、播放器、视频验收工具、测试、项目设计文档，以及既有看板和推荐展示改动；不改业务逻辑、数据库、Spark流程或推荐算法。

## 版本与文件方案

1. 只修改Git忽略规则和交付文档，不暂存、提交、回滚或运行清理命令。
2. outputs根目录Markdown报告、计划和答辩材料纳入候选；历史previous副本保持磁盘保留但忽略，嵌套生产中间目录保持忽略。
3. 对本次视频清理的最终验收JSON、Markdown、SHA256及替换/候选检查记录使用明确白名单；不放行originals、candidates、图片和临时生成目录。
4. 正式视频目录只放行25个基线章节MP4，已有README及5个.gitkeep保留。其他MP4/WebM、.part及.tmp继续忽略。25视频约144.4 MB，纳入本地提交候选；本轮不推送或配置Git LFS。
5. 缓存、失败临时文件、空测试残留采用忽略策略，不删除备份、历史快照或测试源文件。
6. 更新视频目录README中的Git交付说明，保持运行配置与业务代码不变。

## 验证

记录逐文件保留理由、最终git status完整清单、忽略规则正反例、当前25正式视频与最终验收哈希一致性；审查新放行文本中的凭据风险，不回显敏感值。仅运行不访问数据库的相关视频单元测试与前端组件测试，不运行Spark或重新编码媒体。

## 交付与停止条件

交付outputs/git-final-freeze-report.md及outputs/git-final-freeze/中的清单和检查证据。报告明确区分可提交候选、已经提交、数据库冻结与运行环境可复现性。完成后停止，等待用户明确确认，不自动commit。
