# 课程AI独立工作面板设计

2026-10-06。本阶段仅前端布局/展示与测试，不修改后端、AI控制器、接口、数据或学习逻辑。

课程壳最大宽度1600px，宽屏>=1400px保持220px目录、可伸缩正文、450–520px助手。较窄屏幕避免压缩正文，恢复内容下方折叠助手。单一助手实例沿用原控制器。

面板固定标题/课程/模式区域，中部独立滚动且回答优先，底部固定输入/字数/外发确认/发送。引用按真实课程分组、原生details默认折叠，章节点击沿用select事件；历史默认折叠并保留分页和记录查询。错误提示在固定输入区可见，能力检查/不可用提示保留。不新增依赖。桌面高度受视口约束，小屏解除固定高度与内部滚动，短视口允许输入区独立滚动以保留控件。

验证组件实际渲染/交互、折叠引用与历史、模式/外发确认/发送、响应式状态，以及前后端全量测试、TypeScript和构建。真实模型与浏览器截图不由组件测试替代。
