# 毕业答辩前最终验收检查方案

本阶段仅验收与记录，不新增功能、不修改业务代码、数据库结构或已有密码。

验收以正式 localhost:5173 浏览器流程为主，结合只读数据库审计、已有回归测试日志及一次必要的 Spark 离线重算。学生学习/收藏和 AI 提问会产生少量正式记录；记录前后变化，不清理旧数据。

检查项目：学生登录和刷新保持、资源搜索与详情、学习/收藏状态、推荐前后批次与排序；管理员用户/资源/批次及行为查看入口；AI Spark 专业问题回答及历史；未登录权限、空数据和演示种子完整性。

结论区分本轮运行验证、历史测试证据、静态审查及待人工登录完成的项目。不把历史成功当成本轮浏览器通过，不把经验评分当成离线效果提升。

数据模型与架构保持现状。发现问题仅给最小修改建议，未经新授权不实施。
