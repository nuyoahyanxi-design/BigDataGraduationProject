# 推荐实验数据准备设计 v1

日期：2026-10-05。本阶段补充实验数据，复用现有 popular_v1、content_v1 和时间评价流程，不修改算法，不开发前端。

## 数据方式与边界

采用用户允许的明确模拟方式：独立离线状态机 + ODS/DWD Parquet，不绕过 API 直接写数据库。这里的学习者是可供实验使用的模拟用户记录，不是已注册可登录的 MySQL 账号；资源是模拟种子目录，不是线上已发布课程。现有 MySQL 数据保持原状，生成器不导入数据库连接或发布函数。

所有 manifest、种子、配置及报告标注 synthetic_state_machine_v1、固定随机种子。模拟历史时间只是生成协议，不声称真实服务器发生过这些行为；不回填或修改任何数据库时间。旧真实开发样本及其零标签实验保留。

## 资源与学习者

50 个自编种子资源，每主题 10 个：Python、Spark、机器学习、数据库、大数据分析。沿用现有受控标签 python/spark/big-data/machine-learning/sql/mysql/data-analysis 和合法分类；文档/课程/练习三种形式循环，difficulty 1~3，不用难度推断能力。提供标题、摘要、模拟正文及来源/许可说明，禁止复制外部课程全文。

30 名模拟 active learner：20 名显式兴趣与训练行为兼有，5 名无显式兴趣但有训练行为，5 名显式兴趣冷启动。主要主题轮转分配，次要主题不同；没有统一兴趣模板。另有 1 个模拟管理员仅作为资源 created_by 引用，排除推荐评价人口。

## 行为状态机

固定种子 20261005。每个有训练行为的学习者抽取 8 个不同资源；每名用户测试期抽取 3 个训练时尚未开始的资源。每次抽取主题概率：主要主题 0.65、次要主题 0.25、其余 0.10，资源在主题内随机选；不调用推荐算法选择测试标签，不根据指标修改种子或挑最好运行。

训练行为含浏览、开始、完成、收藏；完成必须已有 in_progress。状态机维护每用户资源进度和收藏状态，模拟正式接口状态变化，使用唯一 UUIDv4 形状 ID、schema_version=1、resource_version=1、UTC 毫秒时刻、合法来源/前后状态及现有 SHA256 指纹规范。重复状态操作记 is_effective=0，由现有清洗规则排除。不是实际 API 事务/并发验收。

测试每资源先浏览再开始，部分完成和收藏；测试标签自然来自已有学习开始/完成/收藏协议。第一个测试资源保证合法完成以覆盖流程，三个学习开始保证每用户都有测试正样本。测试资源选取依赖生成时已知训练状态及固定潜在偏好，不依赖推荐结果。由此构造的主题相关性可能有利于内容推荐，必须披露此偏置。

## 时间顺序和防泄漏

模拟用户/资源元数据创建于 UTC 2026-10-01 08:00；训练行为在 10-01/10-02，训练快照截止 2026-10-02 23:59:59.000；测试行为在 10-03，测试快照截止 2026-10-03 23:59:59.000。全部早于当前运行时间。

先只生成训练事件和进度/收藏并写完训练 ODS/DWD，再生成测试事件及测试结束状态。训练与测试 UUID 不交叉。训练画像/热度/候选过滤只读训练冻结文件，不读测试进度或全历史画像。用户兴趣与资源标签在训练前创建，测试不更新元数据。

模拟批次 ID 使用时间+数据/生成器摘要，source_system/source_database 明确 synthetic；不更新生产 pipeline、画像、推荐 latest。实验显式传入这两个批次和 data_origin，不修改旧空样本实验默认配置。相同种子/代码/参数的逻辑数据确定性一致，重复发布不覆盖已存在快照。

## 流程与产物

新增纯数据生成工具 spark/utils/experiment_seed_data.py、阶段编排 spark/jobs/prepare_experiment_data.py、配置 spark/configs/experiment-data-preparation.json 和专用测试。沿用 schema_for、clean_events、既有实验 run；无新增算法。

阶段 outputs/experiment-data-preparation/<run_id> 保存种子 JSON、模拟用户/资源映射、生成配置、各行为统计、清洗报告、验证及实验关联。模拟 ODS/DWD 存 data/ods 和 data/dwd 的独立批次；推荐实验仍存 outputs/experiments/recommendation/<实验ID>，包含 Recall@10/NDCG@10/Coverage、版本、参数、耗时和报告。

验收：资源≥50、学习者≥30、标签受控、不同兴趣、状态机合法、唯一事件、正时间顺序、现有 DWD 无异常、训练快照不含测试事件/完成状态、每用户可评价测试标签、推荐和指标实际运行、算法源码未改变。报告只描述模拟样本指标，不能将内容提升推广到真实学习者。
