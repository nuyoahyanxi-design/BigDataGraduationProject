# Windows一键启动本地配置设计

本阶段只改启动与本地配置，不改AI请求、后端业务或数据库。

优先级按字段：非空系统环境变量 > 根目录.env.local > 交互输入。模型首选AGNES_MODEL，兼容AGNES_MODEL_ID（同属环境变量，AGNES_MODEL优先）。环境变量由PowerShell通过WSLENV按变量名传入WSL，不在命令行传值。

首次运行安全配置工具时若文件缺失，提示缺失字段；Key用getpass隐藏输入。验证通过后独占创建文件，禁止覆盖原文件；已有文件缺字段或为空时明确提示并补充缺失值，保留原有效值，环境覆盖不反写文件。文件只允许两个键，不执行或source配置内容；不接收换行、占位值或非法模型名，不输出文件内容。

Windows启动器在启动后端之前运行配置工具，不调用Get-Acl或Windows权限模块；随后按原方式启动后端。直接Ubuntu启动使用同一加载函数，文件创建模式0600，Windows文件权限沿用当前目录的原有配置。文件是本地明文凭据，不是加密保险箱；不得上传或分享。

.gitignore显式忽略.env、.env.local，允许.env.local.example。首次配置和重用测试全部使用临时目录占位凭据，不删除真实配置。缺文件提示、缺值、环境优先、重复启动、非法配置、无密钥回显、Git忽略、WSL环境转发均验证。

实际Key由用户在本机配置窗口输入；如未完成，报告明确说明未完成，不能宣称真实配置成功。已有后端复用规则保持；配置变化需用户停止旧后端后重新启动才能生效。

## Windows兼容修复（2026-10-05）

用户反馈普通Windows PowerShell无法加载Microsoft.PowerShell.Security模块，Get-Acl导致配置成功后启动中断。启动入口及测试不再调用Get-Acl、Set-Acl或ACL辅助函数，保持已有文件与隐藏输入流程。文件权限沿用本机设置，启动器不自动检查或重设Windows ACL。配置-only和完整冷启动均需在Windows PowerShell中实测。
