# 课程学习页面UI优化设计

本阶段只修改Vue模板和CSS，不修改接口、数据库、学习状态、章节事件或播放事件。目录异常原因是全局nav的横向flex布局继承到章节目录，将标题与多个按钮同时挤入240px列。

局部覆盖章节目录为block，按钮完整宽度并正常横向排字；保持全部章节、当前aria-current高亮、已完成标记、disabled和select事件。课程页桌面260px目录加可伸缩内容区，总宽度不超过1200px；900px以下目录和正文上下排列。仅对course-learning路由附加页面宽度类，不影响其他页布局。

右侧保留原标题、视频和教学内容、原完成按钮；16:9视频contain展示。正文限制800px，案例理解和常见误区继续从既有Markdown显示；代码块用深色背景与局部水平滚动，保留换行和安全文本。教学目标、标签和练习适度分区。

设计不改变API或计算；新增真实章节导航组件的SSR测试，核对长标题完整保留、课程名称、当前章节、禁用语义及完成标记，再运行npm test和npm run build。CSS静态复核不等同实际浏览器视觉验收。
