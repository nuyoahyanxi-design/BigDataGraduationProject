# AI课程视频正式验收设计

本阶段授权实现只读最终验收工具。复用现有目录扫描和MySQL只读快照，不修改业务代码、数据库、视频或Spark。输出独立时间戳JSON/Markdown及SHA256，不覆盖旧报告。

验收基线固定为本次已确定的5门课程25章节，并与当前数据库目录逐一对照；未来新增课程不改变本次基线，额外媒体仍报告。检查课程发布状态、章节归属、课程目录、标准MP4路径、大小、容器与视频轨、SHA256。每个有效容器用FFmpeg完整解码视频及可选音频至null，错误或超时不通过；解码缺失不降级通过。按完整解码progress时间检查默认180–300秒，可配置范围与超时。文件前后stat及SHA256复核，发现验收期间替换不通过。

FFmpeg通过--ffmpeg或PATH提供；不自动下载或安装。此工具验证技术质量和规则映射，不代表教学内容正确、浏览器全兼容或正式事件写入验收。保持用户手动完成章节规则。
