# 前端资源学习模块设计

日期：2026-10-05。本阶段只实现学习者资源列表、详情、学习和收藏操作。用户已授权本阶段设计及实现，交付后停止。

## 接口与模型

列表 GET /api/resources 使用 page、page_size、q（标题搜索）、category_code。分类沿用后端受控字典，不增加数据库字段。展示 title、summary、tags、difficulty(1—3)、resource_type(document/course/exercise)。详情 GET /api/resources/{id} 包含正文、外部地址、来源、许可、版本和时间等已有字段。

状态由 GET /api/users/me/progress?resource_id={id} 与 GET /api/users/me/favorites 获取。收藏接口暂不支持资源过滤，因此逐页查询当前用户收藏（每页100）确定状态，不将首屏未命中误判为未收藏。已有事件回执只反映原操作，不取代独立当前状态查询。

行为 POST view/start/complete/favorite、DELETE favorite 均携带 event_uuid(UUIDv4)。浏览还包含 session_id(UUIDv4) 和带时区的 client_occurred_at；其他行为复用本次访问 session_id。不发送 user_id、来源、状态或版本字段。后端返回大写事件类型、is_effective 及状态回执。

## 页面与架构

新增受登录保护的 /resources 与 /resources/:id。通用类型位于 types/resources.ts，接口封装在 api/resources.ts，详情行为控制器位于 services/resource-learning.ts，两个页面负责展示和交互。列表支持分页、提交搜索、分类变更、加载、失败重试和空结果；筛选变化重置第一页。并发列表请求使用序号丢弃旧响应。

详情先加载完整资源与个人状态，再记录一次浏览。路由 ID 使用安全正整数校验；Vue 文本插值展示正文，不使用 v-html。外链仅允许 HTTP(S)，使用 noreferrer/noopener，点击明确打开原资源，不嵌入第三方内容。完整信息仅展示后端已有字段，不增加管理员编辑功能。

## 操作与一致性

not_started 可开始；in_progress 可完成；completed 不再提供学习写操作。收藏按钮根据当前状态切换。写请求期间锁定全部学习按钮，拒绝重复点击。

每次逻辑操作生成唯一 UUID，网络或5xx失败可能已提交，保留原 payload，仅允许重试同一操作，避免生成重复事件。明确4xx拒绝可释放操作；401继续沿用全局退出。浏览记录失败单独提示，允许重试原UUID，不阻止阅读；返回成功后独立刷新状态。状态刷新失败显示提示并禁用业务按钮，允许重新查询，不能把事件提交成功误报为失败后再次生成新行为。浏览每次详情访问计一次，刷新为新访问，不宣称停留时长或真实学完。

## 验证与阶段边界

执行类型检查、构建和既有认证回归。新增测试覆盖列表分页/搜索/分类、详情、登录保护、五类事件、收藏切换、重复UUID重放、未知提交结果重试及状态刷新失败。真实API测试创建限定前缀临时学习者，使用已有已发布资源，随机密码仅在内存；清理仅临时用户的事件、收藏和进度，再清理用户，不修改已有资源或用户。保存测试日志及数据清理证据。

不开发推荐、看板、后台或AI，不改变数据库、后端和Spark。无个人收藏列表页、富文本渲染、学习时长、离线队列。收藏状态逐页读取可在规模扩大后单独设计后端过滤优化；本阶段不扩展接口。

浏览器组件验证入口为 frontend/tests/resource-ui.html，使用模拟身份和13条模拟资源并显示明确标记。它引入同一组实际页面、控制器及组件，检查分页、搜索、分类、空结果、详情和按钮变化，不访问真实后端，不属于生产页面或构建入口。真实接口与数据库事件链路由独立集成测试验证，两类证据不得混称完整真人端到端验收。未知提交结果的 UUID 保留限于当前详情实例，刷新或离开页面会丢失；不实现离线队列。
