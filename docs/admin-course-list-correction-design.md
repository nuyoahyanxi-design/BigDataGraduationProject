# 管理员正式课程列表修正设计

日期：2026-10-05。

## 已确认原因

正式课程1068—1072在resources中的resource_type均为document，各有5个章节；旧页面使用resource_type=course筛选，仅显示验收资源2和5。不能为解决展示问题改变已有数据类型。

## 技术方案

新增仅管理员GET /api/admin/courses，从resources读取所有未删除教学资源，不限定resource_type；管理员课程管理专用过滤ID 1—6、406及准确标题数据库验收资源1—6。过滤在分页、搜索、total统计之前执行。原资源管理页面、普通资源查询和推荐显示规则不受本阶段影响。

左连接按resource_id聚合的course_chapters数量，返回原资源摘要加chapter_count；无章节返回0，可进入现有章节管理创建第一章。支持草稿、发布、隐藏、全部状态，标题搜索和分页；新接口严格限制查询参数，要求管理员权限。

页面展示名称、简介、状态、章节数量和更新时间，继续支持编辑课程与管理章节。创建新课程仍使用course类型；编辑已有资源保留原resource_type，不自动重分类。章节CRUD和目录冻结规则不变，不改数据库结构、章节、学习进度、推荐、画像或Spark。

## 验证

真实数据库只读验证5门课程全部出现且各5章；测试资源管理页仍可见但课程列表/搜索/分页总数排除。隔离夹具验证各resource_type均可显示、0章资源可新增第一章、类型编辑保留、权限和参数。前端验证新API、字段展示与操作；运行全量测试/类型检查/构建，比较全部25章和受保护业务数据快照。

## 编辑兼容补充

真实资源标签包含rdd、pyspark、hadoop、hdfs、ml、大数据、数据库，均已在后端INTEREST_TAGS允许，但前端受控选项尚未同步。同步前端已有合法标签选项，不增加后端词表、不修改资源标签或推荐算法，新增五组正式课程标签校验测试。
