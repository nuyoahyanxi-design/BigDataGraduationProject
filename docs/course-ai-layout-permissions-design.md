# 课程AI布局与开发权限设计

日期：2026-10-05。本阶段仅调整学习页布局和AI许可配置，保留原问答、引用、学习流程与数据库结构。

桌面>=1200px：外层两列，左侧包含原章节目录/教学内容，右侧360px助手粘性定位top24px，面板高度min(720px,视口高度-48px)，正文/历史在面板内部独立滚动。使用单一助手实例，移动到课程内容外，不复制桌面/手机两份问答状态。桌面默认展开；小屏恢复正文下方可折叠面板，不设固定高度/独立滚动，不自动发送问题。

安全策略：AISettings新增allow_all_resources及allows_resource统一许可函数。APP_ENV默认为production。只有APP_ENV=development且AI_ALLOWED_RESOURCE_IDS=*允许全部可见教学资源；生产*为无效配置，指定ID/空白名单仍保留。通配只替代资源ID命中，不改变published、隐藏406、认证、用户隔离、外发确认、资料凭据检查、限额/并发或供应商调用。

本机授权开发配置放configs/runtime.local.env（非密钥、Git忽略），APP_ENV=development及AI_ALLOWED_RESOURCE_IDS=*；模板runtime.local.env.example展示生产默认拒绝配置。通过独立严格解析器在现有后端启动脚本加载，系统环境变量优先，未设置且无本地文件时仍production+空名单。Windows启动器仅转发这两个变量名称，不写Key。原.env.local格式与凭据管理不变。

测试覆盖：桌面默认展开、移动端展开/收起、单实例布局、真实引用未变；开发通配成功、生产通配拒绝、指定/空名单、草稿/下架/隐藏、认证、凭据拒绝及原历史保护。全量前后端测试、TS、构建和启动环境核验；已有课程/章节/学习数据前后摘要核验。
