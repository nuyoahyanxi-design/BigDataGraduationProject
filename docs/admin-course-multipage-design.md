# 管理员课程后台多页面设计

日期：2026-10-05。本阶段仅调整前端页面责任与路由，不改任何后端接口、权限、学习进度、数据库、推荐、Spark或AI。

## 页面结构

- /admin/courses：仅课程列表/搜索/分页及创建入口，卡片包含标题、简介、状态、章节数、更新时间；编辑和章节管理直接导航，不在底部展开。
- /admin/courses/:id/edit：课程信息编辑，明显返回按钮、独立表单、保存反馈。保留原介绍及全部元数据，保留原资源类型；发布/隐藏移到此页，继续用原接口。
- /admin/courses/:id/chapters：章节列表，课程名、标题、视频地址、排序，新增/编辑路由导航；删除为短小二次确认，后端保护不变。
- /admin/courses/:courseId/chapters/:chapterId/edit：独立章节内容表单，Markdown、教学目标、知识点、代码及练习；保留视频元数据、排序能力，明显返回章节列表按钮。
- /admin/courses/new、/admin/courses/:courseId/chapters/new：保留原创建课程与新增章节能力，复用独立编辑页面。创建成功跳转该条目的编辑URL，避免再次创建。

所有路由沿用requiresAuth、roles=[admin]及forbiddenRoute；学习者仍进入403，后端认证仍独立生效。非法编号、课程或章节不存在时显示错误，不发送写入请求。页面切换刷新可从URL加载，不依赖上一页内存。

## 实现边界

复用现有AdminCourses控制器、字段验证和API；增加保存结果及课程元数据给独立页面使用，不修改业务语义。各页面使用独立控制器实例；路由参数变化时重新创建控制器并校验当前实例，防止跨课程残留。列表不再加载编辑数据。保存失败保留表单，成功提示；加载与提交期间禁用重复操作；新旧课程类型和合法标签保留。

保持panel/Element Plus风格，内容最大宽度1100px，表单最大900px；宽屏两列基础字段，小屏单列和按钮换行；不使用大型编辑弹窗。路由导航滚动到顶部。

## 验证

真实Vue组件和实际Router测试：列表只有跳转按钮、表单无内联、直接URL加载、课程保存/创建、章节新增/编辑、返回、404/非法编号、重复提交、409删除保护、管理员/学习者/未登录权限。全量前后端测试、TS检查、生产构建；25章节及业务数据只读快照一致。未自动编辑正式课程。
