# AI课程视频生产交付设计

本阶段授权HeyGen首批5个视频生产、MP4导入与验收；不改业务代码、数据库、Spark、Git提交或正式批次。剩余20章仅计划。

先完整解析既有25章制作包，整理标题、目标、五场景脚本、口播、PPT结构、提示词和预算时长。原方案PySpark章6–10与本轮新标题/顺序不一致，须获得内容选择后才生成与绑定，不能错配。

统一教师视觉规范：高校数据工程教师、普通话、课堂/实验室背景、16:9 1080p、白底深蓝PPT、清晰中文字幕、教师小窗不遮代码。Avatar采用用户从真实HeyGen图库选择的look ID，声音与背景实际配置须核实；不得虚构ID或声称云端模板已建立。精确脚本、代码与图示进入多场景制作，首批验证后才复用20章。

视频先暂存outputs交付目录，审核真实画面与内容并全量解码、测时长和SHA256后才进入frontend/public/videos/course_1069标准路径。不得把.pending任务或样本片当作正式视频。全量工具固定25章，首批5个即使合格仍有20缺失，整体不能标为通过。

正式登录与播放会触发既有学习写入，完成动作亦写进度。默认遵守不写数据库约束，隔离浏览器与事件测试；若用户明确授权正式学习动作才能执行。本阶段不借视频验收触发Spark或发布指针变化。
